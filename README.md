# Zoah

I build sharp AI-native tools for noisy systems.

My taste is simple: useful software, fast loops, low ceremony, clear leverage. I like tools that remove friction without asking for attention, and interfaces that make people feel more capable the moment they touch them.

Current focus:

- privacy-first browser extensions
- AI workbenches and local automation
- open-source utilities that turn chaos into clean workflows
- small products with unusually high leverage

Recent project:

- [X Reply Janitor](https://github.com/bahuang081-svg/x-reply-janitor) - a local browser extension that hides spammy bot replies on X/Twitter without the X API, account tokens, telemetry, or remote moderation.

Principles:

- ship the useful thing first
- keep data local when local is enough
- make defaults strong and controls honest
- optimize for clarity, not noise

I am interested in tools that feel inevitable after you use them once.
